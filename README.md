# SRIRAM's IAS Landing Page (Updated)

A professional landing page for SRIRAM's IAS, designed to provide information about courses, faculty, and admissions.

 🚀 Features
* Responsive Design.
* Modern UI:* Clean and easy-to-navigate interface.
* Course Overview:* Detailed sections for different IAS preparation programs.

🛠️ Built With
* HTML5
* CSS3
* JavaScript

📂 Project Structure
* index.html - The main entry point.
* style.css - All styling and layouts.
* script.js - Interactive elements.
* /assets - Images and icons.
